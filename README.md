# Bash Scripting for DevOps & Linux Automation

This repository contains my hands-on practice while learning Bash shell scripting for DevOps, Linux administration, and automation.

## Topics Covered

### Bash Basics

* Shebang (`#!/bin/bash`)
* Variables
* User input using `read`
* Command line arguments (`$1`, `$2`)
* Environment variables
* Output using `echo`

### Conditional Statements

* `if`, `elif`, `else`
* Numeric comparisons
* String comparisons
* Nested conditions
* Input validation using regex

### Loops

* `for` loops
* `while` loops
* Arithmetic operations
* Odd/even number logic

### Functions

* Creating functions
* Passing arguments to functions
* Reusable scripting logic

### File & Directory Operations

* File existence checks
* Directory creation
* Automatic file creation
* Exit status handling using `$?`
* Logical operators (`&&`, `||`)

### Text Processing

* Pipes (`|`)
* `grep`
* `cut`
* `awk`
* `sed`

### System Administration & Monitoring

* Process monitoring
* Service management
* Automatic service recovery
* System health monitoring
* Deployment verification
* Failed login detection

### Backup & Log Management

* Log analysis
* Backup automation
* Error detection
* Log filtering

### User & Configuration Management

* User creation and management
* Configuration file parsing
* Employee data processing
* Report generation
